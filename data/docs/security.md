# Orbita Cloud — Account Security

Two-factor authentication (2FA) is optional on the Starter plan and mandatory on the Team and Enterprise plans. Orbita Cloud supports authenticator apps (TOTP) and hardware security keys (WebAuthn). SMS codes are not supported.

All data is encrypted at rest with AES-256 and in transit with TLS 1.3. Backups are taken every 6 hours and kept for 35 days.

If a user loses access to their 2FA device, a workspace admin can reset it. Users without an admin must contact support and verify their identity with a government-issued ID.
